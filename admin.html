      Tournois suivis

      Nouvel événement

        Bookmarklet de mise à jour

        Glisse ce bouton dans ta barre de favoris. Sur la page coverage fabtcg.com, clique-le pour envoyer les classements directement.

        Configure ta clé API dans l'onglet Analytics d'abord.

        Suivi live

        Choisis le tournoi et appuie sur Démarrer : ton PC (relais) met les classements à jour toutes les 90 s, même téléphone verrouillé.

        Chargement…
        Installer le relais sur ton PC (une seule fois)
        1. Installe Node.js (version LTS) si ce n'est pas déjà fait.
        2. Dans le dossier du site, double-clique sur scripts/live-agent.bat.
        3. À la première ouverture, colle ta clé API (celle de l'onglet Analytics).
        4. Laisse la fenêtre ouverte pendant l'événement et empêche le PC de se mettre en veille. Le statut ci-dessus passe au vert.
        Plan B : bookmarklet sur le téléphone (sans PC)

        Le suivi tourne dans le navigateur du téléphone. L'écran reste allumé automatiquement, mais la page doit rester ouverte au premier plan.

        Android (Chrome)

        1. Copie le code avec le bouton ci-dessus.
        2. Ajoute n'importe quelle page aux favoris (☆), puis modifie ce favori : nom baf, et colle le code à la place de l'adresse.
        3. Pendant l'événement, ouvre la page coverage sur fabtcg.com, tape baf dans la barre d'adresse et choisis le favori ★ baf dans les suggestions.

        iPhone (Safari)

        1. Copie le code avec le bouton ci-dessus.
        2. Ajoute n'importe quelle page aux favoris (Partager → Ajouter un signet), puis modifie ce signet : colle le code à la place de l'adresse.
        3. Pendant l'événement, ouvre la page coverage sur fabtcg.com, puis ouvre tes signets et touche le signet BAF.
